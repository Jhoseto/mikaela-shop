# Моят Магазин Микаела

Онлайн магазин с български интерфейс, поръчване като гост и плащане при доставка. Публичен каталог, служебен панел и мобилен изглед за доставчици споделят една база. Първоначалните артикули идват от действителната промоционална брошура. Служителите решават кои варианти се предлагат в обекта и попълват приложимите данни от етикет.

## Локален достъп в подготвения проект

Двойно щракване върху [restart.bat](restart.bat) рестартира основния магазин, локалната база и фоновите задачи. Скриптът спира и демонстрацията, ако е стартирана. След рестарта отворете [магазина](http://localhost:3000) или [администрацията](http://localhost:3000/admin).

| Среда | Магазин | Администрация |
| --- | --- | --- |
| Основен магазин с всички предложения от текущата брошура | http://localhost:3000 | http://localhost:3000/admin |
| Демонстрация с тестови поръчки | http://localhost:3100 | http://localhost:3100/admin |

На порт 3000 са включени локални поръчки за 56-те артикула от брошурата за 9–22 ноември 2026 г. Изберете продуктите, уточнете вкуса или разфасовката при нужда и посочете интервал в „Локален тестов район“. Поръчките се записват в основната база и в администрацията са обозначени като тестови. Външните известия и реалната доставка са изключени.

Двете бази и двете директории за изображения са самостоятелни. Паролите за локалния собственик и трите демонстрационни роли са генерирани при създаването и се пазят в `var/private/owner-access.txt` и `var/private/demo-access.txt`. Файловете са предназначени за оператора. При първия вход собственикът регистрира приложение за двуфакторна проверка и прибира резервните кодове.

## Стартиране на нов Windows компютър

Използвайте Node.js 24, npm, PostgreSQL 18 с разширението pg_trgm и Python с библиотеките за обработка на PDF. Отворете PowerShell в главната директория.

```powershell
npm ci
& ./scripts/setup-postgres.ps1
npm run db:start
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r python/requirements.txt
npm run migrate
npm run brochure -- check
node --env-file=.env.local --import tsx scripts/bootstrap-owner.ts
npm run build
& ./scripts/start-local.ps1 -Mode shop
& ./scripts/start-local.ps1 -Mode worker
```

Командата за PostgreSQL подготвя постоянна база в `var/postgres-data`, на адрес 127.0.0.1 и порт 55440, и генерира ключ за сесиите и парола в `.env.local`. При собствен PostgreSQL задайте връзката и тайните според `.env.example`. Не стартирайте локалния bootstrap за база, когато използвате отдалечена услуга. Укажете пътя към вашия Python чрез `BROCHURE_PYTHON`, ако интерпретаторът е извън стандартната проектна среда.

```powershell
npm run demo
& ./scripts/start-local.ps1 -Mode demo
& ./scripts/start-local.ps1 -Mode demo-worker
```

За разработка може да пуснете `npm run dev -- --hostname 127.0.0.1` при свободен порт 3000. За контролирано спиране използвайте `./scripts/stop-local.ps1 -Mode shop` (съответно `demo`, `worker` и `demo-worker`). Първо спрете приложенията и фоновите задачи, ако предстои `npm run db:stop`. След промяна на кода стартирайте нов build и рестартирайте съответните процеси.

## Организация

- `src/app` съдържа клиентските и административните маршрути, API за ценообразуване, поръчки и защитено проследяване.
- `src/commerce` изчислява сумите в центове, съхранява моментното състояние на поръчката и управлява подготовката, плащанията и известията.
- `src/importer` и `python` откриват и разчитат брошури. Версиите и решенията се пазят в PostgreSQL и устойчивото хранилище.
- `migrations` и SQL файловете в `src/importer` се прилагат чрез `npm run migrate`. Миграциите са транзакционни, записват се по име и се изпълняват с взаимно заключване.
- `var` съдържа локалните бази, медии, архиви, служебни записи и резултати от проверките. Не включвайте тази директория и файловете с тайни в публични хранилища.
